# revenge-fonts

Google Sans Flex (main) + JetBrains Mono (code) for Revenge / Bunny.

Static instances cut from the variable fonts:
- Google Sans Flex: wdth 100, GRAD 0, ROND 100, opsz 16, slnt 0 (italics: slnt -10), weights 400-800
- JetBrains Mono: weights 400-800 (SemiBold is used for the code slot)

Both fonts are licensed under the SIL Open Font License.

## Install

Settings → Fonts → Install, then paste:

```
https://raw.githubusercontent.com/Heptex/GoogleSansFlex-JetBrainsMono-Revenge/main/GoogleSansFlex-JetBrainsMono.json
```
